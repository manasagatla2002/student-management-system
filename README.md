# Student Management System

## 📌 Project Description
This is a Spring Boot CRUD application for managing students.

## 🚀 Features
- Create Student
- Get All Students
- Get Student by ID
- Update Student
- Delete Student

## 🛠️ Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- Postman

## 📂 API Endpoints

POST    /students
GET     /students
GET     /students/{id}
PUT     /students/{id}
DELETE  /students/{id}

## ▶️ How to Run
1. Clone the repository
2. Open in IDE
3. Configure database in application.properties
4. Run Spring Boot application
